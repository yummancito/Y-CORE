═══════════════════════════════════════════════════════════════════════════════
                              THE PROBLEM
═══════════════════════════════════════════════════════════════════════════════

SYMPTOM:
  User A downloads game X with Y-core on PC-A ✅
  User A goes to PC-B, launches Steam
  Game X shows [COMPRAR] button instead of [JUGAR] ❌
  Clicking "Jugar" → "No hay licencias" error ❌

AFFECTED VERSIONS:
  v4.3.0 through v4.3.26 (all intermediate versions had the bug)

ROOT CAUSE:
  ❌ lua_content (depot manifest information) was NOT being passed through
    the install pipeline from the API to the backend

  ❌ Without lua_content, the ACF file has EMPTY InstalledDepots block

  ❌ Steam sees empty InstalledDepots → "No depots to install"
    → Shows "Comprar" instead of "Descargar"

═══════════════════════════════════════════════════════════════════════════════
                              THE SOLUTION
═══════════════════════════════════════════════════════════════════════════════

CHANGES:      Only 3 lines of code added (0 lines removed)
FILES:        2 files modified
COMPLEXITY:   Low (simple parameter forwarding)
BREAKING:     No breaking changes

MODIFIED FILES:
  1. src/services/install.service.ts
     - Added luaContent?: string parameter to startV2Download()
     - Forward luaContent in downloadService.startFromApi() call

  2. src/hooks/useInstallProcessor.ts
     - Pass game.lua_content to startV2Download()

  3. electron/services/download.service.ts
     - NO changes (was already correct, just needed input)

COMMIT MESSAGE:
