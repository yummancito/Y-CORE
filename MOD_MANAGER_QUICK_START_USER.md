# Y-Core Mod Manager - Quick Start Guide (5 Minutes)

## Your First 5 Minutes

Everything you need to know to install your first mod in under 5 minutes.

---

## Step 1: Launch and Select Your Game (1 minute)

1. Open **Y-Core Mod Manager**
2. A dropdown appears at the top: "Select Game"
3. Click it and choose your game (e.g., "Skyrim Special Edition")
4. Y-Core scans for existing mods (takes 5-10 seconds)
5. **You're ready!**

> If no dropdown appears: Make sure game is installed. Y-Core detects installed games automatically.

---

## Step 2: Find a Mod (1 minute)

1. Click the **"Catálogo"** tab (looks like a library/catalog icon)
2. You'll see a list of available mods
3. Look for something interesting:
   - **Filter by category** on the left (if available)
   - **Search** for specific mod names
   - **Sort** by "Popular" or "Highest Rated"

**Pro tip:** Start with highly-rated mods (4+ stars). They're tested and safe.

---

## Step 3: Install Your First Mod (1 minute)

**Found a mod you like?**

1. Click on it to see details
2. Scroll down and read the description
3. Look for:
   - ⭐ **Rating** - higher is better
   - 📊 **Number of downloads** - more is safer
   - ✅ **Malware scan status** - should be green/clean

4. Click the blue **"Instalar"** button
5. Wait for the progress bar (10-30 seconds)
6. You'll see: **"¡Mod instalado correctamente!"** (Mod installed successfully!)

**That's it!** Your first mod is installed. Seriously, that's all.

---

## Step 4: Use Your Mod (2 minutes)

1. **Close Y-Core** completely
2. **Launch your game** normally
3. Look for your mod's changes:
   - New menu item?
   - New items in inventory?
   - Different graphics/visuals?
   - New gameplay feature?

4. **Play for 5 minutes** to test
5. If working great, you're done with this mod!

> If mod doesn't work: See "Troubleshooting" section below

---

## Congratulations! 🎉

You've successfully installed your first mod. You now understand 80% of mod management.

## Three Things to Remember

### 1. Always Keep Backups ON
- Settings > "Create Backup Before Install" = ON
- Automatic safety net
- If something breaks, you can undo it

### 2. Test One Mod at a Time
- Install mod #1
- Play 10 minutes
- Install mod #2
- This prevents "which mod broke it?" guessing game

### 3. Check Mod Details Before Installing
- Read description (what does it do?)
- Check rating (4+ stars is safe)
- Check for "Requires:" (dependencies)
- Takes 30 seconds, saves hours

## Safety: Malware Scanning Explained

Every mod gets scanned before install:

- **✅ Green icon** = Safe, install with confidence
- **⚠️ Orange icon** = Suspicious, investigate first
- **❌ Red icon** = Dangerous, don't install

**Normal scan takes 10-20 seconds.** This is the security system protecting you. Worth the wait.

## Simple Troubleshooting

### "Mod installed but I don't see it in game"

**Fix (30 seconds):**
1. Go to "Mis Mods"
2. Find your mod
3. Check the eye icon—is it open 👁️ or closed 🚫?
4. If closed, click it to open (enable it)
5. Close Y-Core and restart game

**Why?** Mods need to be enabled to work. Disabling ≠ uninstalling.

### "Game crashed after installing mod"

**Fix (2 minutes):**
1. Go to "Mis Mods"
2. Find the newest mod you installed
3. Click trash to uninstall it
4. Restart game
5. Game should work again
6. That mod wasn't compatible with your setup

**Why?** Some mods conflict. This helps identify which one.

### "Mod said it installed but it's not in my Mods list"

**Fix (1 minute):**
1. Open Y-Core Settings (gear icon)
2. Click "Clear Cache"
3. Restart Y-Core
4. Go to "Mis Mods"
5. Your mod should now appear

**Why?** Sometimes cache gets stale.

## Pro Tips for Beginners

### Tip 1: Read Mod Descriptions
Every good mod has:
- **What it does** - clear explanation
- **Compatibility** - "Works with Skyrim SE"
- **Installation** - usually just "subscribe"
- **Known issues** - helps you avoid problems

Spend 30 seconds reading. Saves hours later.

### Tip 2: Look at Mod Ratings
- ⭐⭐⭐⭐⭐ (5 stars) = Excellent, highly recommended
- ⭐⭐⭐⭐ (4 stars) = Very good, safe choice
- ⭐⭐⭐ (3 stars) = Good but might have issues
- ⭐⭐ (2 stars) = Many complaints, avoid
- ⭐ (1 star) = Broken/malicious, definitely avoid

**Most popular mods:** 4-5 stars. Start there.

### Tip 3: Create Backup Before Testing Risky Mod
1. Go to "Gestor Activos"
2. Click "Crear Copia de Seguridad"
3. Name it (e.g., "Before Risky Mod Test")
4. Now install risky mod
5. If it breaks, click "Restaurar" to get back
6. Takes only 30 seconds to revert

### Tip 4: Start Small, Build Up
- Install 5-10 mods = stable, fun, no problems
- Install 30-50 mods = needs careful management
- Install 100+ mods = requires expertise

Start with 5-10 while learning.

### Tip 5: Join Communities
- Reddit: r/Skyrim, r/Fallout, etc. (very helpful)
- YouTube: Search "[Game] modding guide"
- Discord: Join game modding servers
- Other gamers have solved your problem already

## Common Questions

### Q: Will my saves break?
**A:** No! Your character/save file is separate from mods. Mods only change game files. Uninstall mods and your save is fine.

### Q: Can I uninstall mods?
**A:** Yes! Click trash icon. Takes 30 seconds. Game goes back to normal.

### Q: Do mods cost money?
**A:** No! All mods are free. If someone asks for payment, it's a scam.

### Q: Can I install 100 mods?
**A:** Technically yes. Practically, 30-60 mods is comfortable for most PCs. More mods = more potential conflicts = more troubleshooting.

### Q: What if Y-Core crashes?
**A:** Restart it. Doesn't hurt anything. Your game and mods are safe.

## What NOT to Do

❌ **Don't install 20 mods at once**
- Can't identify which one breaks things
- One mod at a time + test is best way

❌ **Don't click "Instalar" then close Y-Core**
- Wait for completion (blue bar finishes)
- Closing early can corrupt installation

❌ **Don't ignore malware warnings**
- Red ❌ icon = don't install
- Orange ⚠️ = research before installing
- Y-Core is protecting you

❌ **Don't skip reading mod description**
- Takes 30 seconds
- Prevents hours of troubleshooting
- Tells you dependencies and compatibility

❌ **Don't delete all backups**
- Keep at least 2-3 recent ones
- They're your "undo" button
- They don't cost much space
